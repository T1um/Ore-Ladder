# Changelog

## 1.0.0
- Ore ladder: Coal → Copper → Iron → Gold → (Nether Gold, optional) → Redstone → Quartz → Lapis → Diamond → Emerald → Netherite.
- FPS cap system (client-side frame limiter driven by the server): +FPS per ore, random tasks, penalties for skipping ores.
- 32 random tasks with rewards and failure penalties.
- Two difficulties selectable on the Create World screen: Normal and Very Extreme (18 random permanent restrictions).
- Final trial: Ender Dragon + delivering Dragon Egg and Elytra to a chest at 0, y, 0.
- English and Russian (auto-detected, /ladder lang ru|en).
